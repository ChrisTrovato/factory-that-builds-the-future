# Validation and publication boundary

Run `npm run check` from the repository root. The runner performs syntax checks on 22 public JavaScript modules and executes nine suites:

1. Core engineering models
2. Math studio
3. Curriculum references
4. Practice content
5. Backup parsing and merging
6. Feedback control
7. Arcade calculations and interaction lifecycle
8. Attributed video catalog
9. Expanded projects and expeditions

The public site files were copied from the production allowlist. Private originals, attachments, account metadata, deployment responses, credential files, raw chat exports, and browser learning records are outside this repository. Public source text was checked for local user paths and credential patterns before import. This is a focused publication review, not a claim of an exhaustive security audit.

The live October 29 release also received desktop/phone browser checks and a public-asset integrity comparison. Those observations are historical release evidence; the repository's reproducible numerical/content checks are the current verification entry point.

After modifying an interactive feature, exercise its real browser flow as well as relevant numerical checks. Check keyboard controls, reset, route cleanup, mobile overflow, and exported results. A green test suite does not by itself establish accessibility compliance or real-world physical validity.
